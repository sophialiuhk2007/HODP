# MBTA Station Closures Map

An interactive map for the [Harvard Open Data Project](https://www.hodp.org/) showing which MBTA stations
have the most service failures and closures.

**[View the map →](https://sophialiuhk2007.github.io/HODP/)**

The whole visualization is the single self-contained page [`index.html`](index.html). Open it in a browser
to run it locally.

See also: [hodp-grade-cap-enrollment](https://github.com/sophialiuhk2007/hodp-grade-cap-enrollment), an
HODP analysis of Harvard course enrollment.
